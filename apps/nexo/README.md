# Aplicación provisional NexoEntrega 360

Laravel 12 + PostgreSQL 17. Módulos Identity, Requests, Inventory, Queries y AI. Interfaz servida por Blade y JavaScript nativo.

Desde la raíz: `docker compose up -d --build`. Consultar [runbook](../../docs/delivery/runbook-provisional.md) y [resultados](../../docs/evidence/runtime/verification.md). No es entrega final ni aprobación G1/G2.

Laravel conserva su licencia MIT en las dependencias. Las cuentas y datos iniciales son ficticios.
